# SmartFleet - Vehicle Management System

An object-oriented Java application built to manage logistics fleet operations and rental calculations.

## Key Features
* **OOP Abstraction & Polymorphism:** Utilizes an abstract `Vehicle` base class with concrete `Car` and `Truck` implementations that dynamically compute ZMW rental costs.
* **Encapsulation:** Protects internal object states (vehicle IDs, models, rates) through explicit public interfaces.
* **Interface Contracts:** Implements a `Maintainable` interface on heavy-duty vehicles to track servicing requirements.

## Tech Stack
* **Language:** Java (JDK 17+)
* **Concepts:** Object-Oriented Programming (OOP), Polymorphism, Interfaces, Abstraction
